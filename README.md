# Ryoeh — IT & Cybersecurity Portfolio

My personal portfolio website, built to showcase my interests in IT, networking, and cybersecurity.

## About

I'm an IT student interested in understanding how computers, networks, and security systems work. I enjoy learning by doing, experimenting in safe environments, and building a solid foundation in technology.

This website reflects my learning journey and the things I enjoy exploring along the way.

## Features

- **Interactive dot matrix design** with animated LED effects and cursor interactions.
- **Hardware glyph interface** with different lighting modes and sound effects.
- **Cyber arcade** featuring a playable Snake game and an interactive synthesizer.
- **Interactive terminal** with commands related to my profile, certifications, and cybersecurity concepts.
- **About me** section describing my interests, approach to learning, and goals.
- **Certifications** showcasing my current qualifications.
- **Dark and light themes**, audio controls, and a live digital clock.

## Certifications

- **Cambridge English B1 Preliminary** — English language qualification.
- **ICDL Essentials** — Essential digital and computer skills.
- **Introduction to Cybersecurity** — Foundational cybersecurity knowledge.

## Technologies

The website uses web technologies to create its interface, animations, and interactive features, including:

- HTML
- CSS
- JavaScript
- Canvas API
- SVG
- Web Audio API

No external audio files are needed for the synthesized sound effects.

## Goals

I'm currently focused on improving my knowledge of networking, cybersecurity, and programming. My goal is to develop practical skills, work on personal projects, and gradually explore more advanced topics in information security.

I believe in understanding the fundamentals, learning through experimentation, and making consistent progress.
